Tentang perhitungan rute

Peta dan garis rute ditampilkan menggunakan modul CrootJS. Geometri rute jalan diminta dari layanan OSRM publik melalui internet; tidak diperlukan library JavaScript pemetaan tambahan. Jarak dan waktu tempuh merupakan perkiraan, bukan data lalu lintas langsung.

Berangkat Tujuan Rute
Klik “Pilih di peta”, lalu klik lokasi. Peta dan garis GeoJSON digambar oleh modul CrootJS.
